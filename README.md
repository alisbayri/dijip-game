# DijiP — Dijital Pazarlama Simülasyon Oyunu

Oyuncuların dijital pazarlama süreçlerini gerçek brieflerle deneyimleyerek öğrendiği ciddi oyun (serious game).

## Özellikler

- 12 gerçek müşteri brief'i (kafe, e-ticaret, B2B SaaS, mobil app, otel, kozmetik, eğitim, sigorta, klinik vb.)
- 5 hedef kitle × 4 kanal × 4 kreatif yaklaşım = 80 strateji kombinasyonu
- Her brief'e özel mini-oyun (Google anahtar kelime / Meta kreatif / Email konu satırı / SEO konu)
- 6 uzman pozisyonuyla ajans yönetimi
- 12 rozet, pazar olayları, performans raporu, zafer ekranı
- LocalStorage ile otomatik kayıt

## Lokal çalıştırma

```bash
npm start
```

Sonra tarayıcıdan `http://localhost:8080` adresini aç.

## Teknoloji

Vanilla JS + Tailwind CDN, tek HTML dosyası, bağımlılık yok. Node.js sadece static server için.
